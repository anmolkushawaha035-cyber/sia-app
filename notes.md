# Sia AI Assistant - Blueprint

Sia = Smart Intelligent Assistant
Creator: Anmol Sir
Language: Hindi + English

## Development Steps
1. Project setup
2. Screens: Splash, Home with avatar, Chat/Voice, Settings
3. Text chat
4. Voice input and voice reply
5. AI brain (secure backend, no API key inside app)
6. Memory
7. Skills: Reminder, Web Search, Notes, Study, PDF, Camera
8. Android actions with Permission Center
9. Agent Control Room
10. Study Mode and JEE Mode
11. Privacy and security
12. Testing and release

## Rules
- Build only from mobile, one step at a time
- Next step only after the previous one is done
- Security and permission rules always followed
